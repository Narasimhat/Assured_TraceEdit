Where your files go
AssuredQC runs in a browser worker. TraceEdit sends each selected control/sample pair to this site's server for analysis. Donor mapping sends the control and donor to the same server. HTML report files are never uploaded. Results stay in this tab until downloaded.

 
The engines retain their own candidate libraries and signal models. AssuredQC's fit window expands to include mapped donor changes; the actual settings are included in your report.
